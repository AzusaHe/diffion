# DiffIon

A shared workspace for CBE236 project. Built for differentiable solver for ion transport and electrochemistry. 

```text
diffion/
├── solver/      # Physics and forward simulation
├── inverse/     # Parameter estimation and optimizer comparisons
├── pinn/        # Physics-informed learning
├── surrogate/   # Surrogate models
├── analysis/    # Diagnostics, evaluation, and figures
└── agent/       # Future experiment automation
```
